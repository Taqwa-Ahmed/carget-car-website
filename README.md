# CarGET - Automotive Showroom Website

>  The project was designed and completed on my second year  **2024-2025** 

CarGET is a clean, modern front-end website designed for a car dealership platform. Users can browse top vehicle brands, view best-selling models, interact with registration forms, and read a dropdown FAQ section.
